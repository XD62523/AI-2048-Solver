# 2048 AI Solver (DSA Project)

A responsive, browser-based implementation of the classic 2048 puzzle game powered by an AI solver, built as a Data Structures and Algorithms (DSA) project. Works seamlessly on both **desktop and mobile devices**—play manually or let the AI take over using adjustable search depths.

🔗 **[Play Live Demo](https://github.io)**

## Features & Controls
* **Cross-Device Manual Play:** 
  * **Desktop:** Use your **Arrow Keys** to slide and merge tiles.
  * **Mobile:** Use **touch/swipe controls** directly on the board.
* **Start AI:** Toggle continuous automated gameplay where the AI plays the game for you.
* **AI Step:** Execute a single optimal move calculated by the AI without turning on full auto-play.
* **Adjustable Search Depth:** Customize how far ahead the AI looks before choosing a move:
  * **Depth 2 (Fast):** Quickest move calculation with shallow lookahead.
  * **Depth 3 (Balanced):** Good balance between move speed and strategic planning.
  * **Depth 4 (Strong):** Deepest lookahead for stronger board evaluation and higher scores.
* **Score Tracking & Reset:** Automatically tracks your current **Score** and **Best** high score, with a **Reset** button to start fresh anytime.

## Getting Started

### Play Online
No installation required—open the **[Live Demo](https://github.io)** in any desktop or mobile browser.

### Run Locally
1. Click the green **Code** button on this repository and select **Download ZIP** (or clone via Git).
2. **Extract the ZIP folder** to your computer.
3. Double-click `index.html` to open and run the game in your web browser.
